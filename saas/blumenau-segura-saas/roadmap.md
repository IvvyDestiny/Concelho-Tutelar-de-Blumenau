# Roadmap - Blumenau Segura SaaS

## Fase 1: MVP (Minimum Viable Product)
- [ ] Estrutura básica do Backend API
- [ ] Implementação do `plnService` e `geoService`
- [ ] Client-SDK simples com formulário de triagem
- [ ] Dashboard básico com métricas

## Fase 2: Inteligência e Expansão
- [ ] Refinamento do PLN para detecção de urgência
- [ ] Integração de alertas automáticos (Email/WhatsApp)
- [ ] Dashboard avançado com mapas de calor

## Fase 3: Escala SaaS
- [ ] Sistema de multi-tenant robusto
- [ ] Painel administrativo completo para prefeituras
- [ ] API pública para integração com outros serviços
